## 项目简介

云端存储器（Cloud Storage）是一款云端存储客户端。本仓库提供 Windows 平台的安装文件下载。

## 下载与版本说明

本仓库提供两个 `.exe` 文件，功能完全相同，区别在于**分发与运行方式**。请根据使用场景选择。

### 1. `云端存储器 Setup 1.0.0.exe`（带 Setup）—— 安装包

**这是什么：** 真正的安装包（Installer）。

**作用：** 双击运行后弹出安装向导（选择安装路径、同意协议等）。安装完成后，会在"开始菜单"或"桌面"生成快捷方式。

**底层原理：** 本质上是一个"解压程序"。运行时把软件核心文件解压到 `C:\Program Files` 或 `AppData` 目录，并写入注册表。

**适用场景：** 正式发布给普通用户。普通用户习惯了"下一步、下一步"的安装方式。

### 2. `云端存储器 1.0.0.exe`（不带 Setup）—— 免安装版

**这是什么：** 免安装版（Portable / 绿色版）。

**作用：** 双击直接运行，无需任何安装步骤。

**底层原理：** 整个软件（包括运行环境）打包进单个 exe。每次双击在后台临时解压运行，关闭后清理。

**适用场景：** 放在 U 盘里带走、发给不想安装软件的朋友、或在无法安装软件的受限电脑上临时使用。

## 版本对比

| 特性 | Setup 版（安装包） | 免 Setup 版（绿色版） |
| --- | --- | --- |
| 安装步骤 | 需要安装向导 | 无需安装，双击即用 |
| 桌面/开始菜单快捷方式 | 会生成 | 不生成 |
| 写入注册表 | 是 | 否 |
| 安装位置 | `C:\Program Files` / `AppData` | 临时目录，关闭后清理 |
| 适合人群 | 普通用户、长期使用 | 便携需求、受限电脑、临时使用 |

---

## 使用提示

- 两个文件任选其一即可，**无需同时安装**。
- 系统要求：Windows 10 及以上（64 位）。
- 若 Windows SmartScreen 提示"未知发布者"，可选择"更多信息 → 仍要运行"。
